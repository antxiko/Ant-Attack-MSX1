Capturas de openMSX de la compilación documentada con perfil Philips VG-8020. Demuestran la imagen, no certifican hardware real.

Qué añade la conversión

  • Capa nativa de SCREEN 2 con un shadow que solo sube las casillas modificadas.
  • Control rotatorio o direccional, redefinición de teclas y cuatro alcances de granada.
  • Cámara corregida, ciudad amarilla y negra y un HUD rediseñado.
  • Secuencias del beeper adaptadas al PSG sin bloquear el juego.
  • El desensamblado de referencia y todas las fuentes del parche.

Araubi completó manualmente los diez niveles. Las pruebas automáticas cubren también cámara, controles, daño, rescates, HUD, tiempo y registros del PSG.

Aplicar el IPS

Aporta tu snapshot Ant_Attack_1983_Quicksilva.z80, SHA-256 aad0783b...32f1cd. El normalizador crea la base determinista que espera el IPS:

python tools\normalize.py
python tools\make_ips.py apply build\Ant_Attack_MSX1_base.rom patch\Ant_Attack_MSX1.ips build\Ant_Attack_MSX1.rom

El resultado debe tener SHA-256 0cd4bb3a...54b1a. No se distribuye el snapshot ni la ROM.
